# 墨中故城探索場景

> 下文為舊探索版紀錄。相同場景路徑現在是 V3 全城連續戰鬥版本，已串接半血逃離與主動入畫；最新操作、資產與驗收見 [V3 交付紀錄](INKBOUND_TOWN_V3.md)。

開啟 `Assets/_Project/Scenes/InkboundTown_Exploration.unity`，按 Play 即可從城外牌坊前進入河鎮。沿用目前玩家的移動、跳躍、翻滾、衝刺與第三人稱鏡頭鍵位。Esc 使用既有暫停介面。此版本專注於探索，未加入 Boss 戰，也未連接道場半血退場流程。

場景以《Unity 水墨河鎮》的近濃遠淡、白牆黑瓦、河面倒影與山水留白為視覺參考。世界沿用附件的「已完成的畫」設定，居民持續走自己的路線，對玩家沒有對話、敵意、注視或閃避反應。

**可探索內容**

- 城外入畫牌坊與石板進城路。
- 蜿蜒河道、兩岸石街、兩座可走過的石拱橋與河岸落腳石階。
- 不同高度的白牆瓦屋、六組布匹／陶器／山貨攤位與連接巷道。
- 可進入的臨河茶館、茶客與店主。
- 約 40 公尺的古樹廣場、棋桌、休息長椅與活動居民。
- 78 名具有日常路線或活動的居民，以及兩名隨渡船行動的漁夫。
- 柳樹、竹叢、古松、蘆葦、屋頂遠景及逐層淡化的水墨山形。
- 河流環境底聲與既有鳥鳴。商販台詞與人群語音未製作。

居民沒有碰撞體或傷害接收元件。地面、牆壁、橋面、橋欄與主要結構具有實體碰撞。落入河道深處時，探索轉接元件會把玩家送回最近的安全岸邊。這個回送只作用於本場景，不修改共用玩家移動或死亡程式。

**散墨互動**

`InkboundEcho` 根據玩家實際腳底高度與移動方向，對鄰近人形局部施加濕墨式輪廓侵蝕和位移。受影響處生成濃淡墨團與彎曲細絲，離開後向當下骨架動畫的取樣位置回流。原本的動畫與日常路線繼續運行，不會回到碰觸時的舊位置。

這是 HLSL 材質、CPU 骨架網格取樣與阻尼回復的即時近似。每個細緻效果預設 176 個取樣點，骨架取樣上限約每秒 20 次，同時最多 5 個細緻散墨效果。它沒有為每名居民求解完整三維流體，也沒有將本版擾動接到武器或 Boss 技能。玩家步行、奔跑及翻滾造成的接觸共用移動擾動入口。

Inspector 可調 `touchRadius`、`returnSeconds`、`flowStrength`、`sampleCount` 和 `maximumDisplacement`。預設主要恢復時間為 1.3 秒，位移上限為 1.35 公尺。模型形體由局部遮罩恢復，離散取樣點持續跟隨正在移動的形體。

Unity 選單 `GeminiGrowUp → 墨中故城 → 建立探索場景` 可重建。重建會覆寫本場景及上述範圍內的生成資產，手動微調前可先複製場景另存版本。生成器會先檢查目前場景是否有未保存變更。新場景已追加至 Build Settings，其餘場景順序保留。

玩家沿用現有 PlayerRig 的場景實例，停用本實例的攻擊與技能控制。共用 PlayerRig、第一階段場景、Boss AI、血量與逃離流程沒有為此版本改寫。探索場景在執行時註冊至現有暫停系統，退出後清除該註冊。

河面共用一張 512×512 的平面反射，每秒最多更新 8 次。靜態建築和道具依材質合併網格，避免每根窗格、樹枝與桌腳各自繪製。尚未完成目標硬體的 GPU 與幀時間量測，沒有宣稱達成 60 FPS。

**驗證與呈現界線**

本輪美術包重製請以 `Docs/INKBOUND_TOWN_ART_ACCEPTANCE.md` 逐項紀錄、`output/inkbound-town/art-revision/required-checks.json` 及新版畫面為準。本輪依使用者要求只做必要的編譯、網格／Shader、五個視角與一名居民接觸回流確認；以下完整移動及戰鬥排除檢查屬於前版結果，本輪未重跑。

已執行的檢查涵蓋場景與材質參考、單一玩家與主鏡頭、虛擬鍵盤前進及跳躍、正式控制器沿入口／市集／石橋／茶館／廣場行走、牆壁碰撞、居民穿透與傷害排除、移動居民散墨及重複恢復、暫停與渡船恢復、落水回送和攻擊停用。結果以 `runtime-checks.json` 的最後狀態為準。

畫面包含實際玩家出生視角、河道石橋、市集、古樹廣場、茶館，以及同一名移動居民在完整、接觸、回流和恢復後的四階段渲染。環境巡檢鏡頭用於觀察不同位置，玩家仍使用既有第三人稱自由鏡頭。

本版是可探索的場景與視覺原型。建築及植物主要採程序化幾何與筆墨材質，精細程度仍可再以手工水墨貼圖、建築細節和植物輪廓提升。完整市井語音、其他關卡的入畫入口、Boss 第二階段、武器造成的擾動與戰鬥演出留待後續工作。
