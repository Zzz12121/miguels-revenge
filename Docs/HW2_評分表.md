### 1. 主選單 & 遊戲流程
- **主選單**（`MainMenu` 場景）：「開始遊戲」、「結束遊戲」按鈕；有存檔時多一個「繼續遊戲」。左側用 GUI Text 說明遊戲規則（三個關卡的目標、生命數、回血方式），右側列出全部操作方式。
- **Game Start**：按「開始遊戲」從第一關開始，畫面淡入並顯示關卡標題。
- **Game Over**：玩家共有 3 條命，倒下後在檢查點復活；命用完顯示 Game Over 畫面，有「從第一關重新開始」「回主選單」按鈕。
- **Game Win**：打倒第三關最終 Boss 後顯示通關畫面，同樣可以重新開始或回主選單。
- **Restart**：遊戲中按 Esc 開暫停選單，可以「重新開始本關」、存檔、讀檔、回主選單。

### 2. 遊戲核心機制（三個關卡）
| 關卡 | 場景 | 主題 | 過關條件與玩法 |
|---|---|---|---|
| 第一關 | `Planet` | 沙漠星球 | 採集草藥向商人換治癒藥水、精力藥水；蜘蛛巢穴裡的蜘蛛從卵中孵化，在巢穴選擇能力路線；跟著地上的流沙找到 Boss 廣場，打倒時鐘 Boss「時間吞噬者」後傳送門開啟 |
| 第二關 | `The_Viking_Village` | 維京村莊 | 擊敗村莊的聖騎士守衛，搭上長船出海，用弓箭擊退敵艦上的弓箭手抵達終點；潛入水中會消耗氧氣 |
| 第三關 | `Floor02` | 地下城 | 隨機生成的地下城房間，走廊有從天而降 / 從地底鑽出的伏擊骷髏，最後打倒石巨人 Boss 通關 |

- 每一關消滅敵人 / 打倒 Boss 後才會開啟傳送門或前進，進入下一個場景。
- 額外機制（第一關）：沙蟲低谷（撐過後獲得一株進階能力植物，選過的能力不會再出現在 Boss 房的植物裡）、檢查點石碑、營火（每座只能用一次，死亡後不會恢復）、能力植物三選一、開戰後流沙牆封住競技場。

### 3. 玩家為人形，所有動作都有動畫
- 玩家是人形骨架的貓戰士（模型匯入設定為 Humanoid），動畫由 Animator（`AC_PlayerCatWarrior`）控制。
- 有動畫的動作：待機（含隨機待機小動作）、走、跑、跳、落下、落地、三段攻擊連擊、舉盾格擋、盾擊、拉弓（第二關）、受擊（四種隨機）、死亡、復活、翻滾（程式控制骨架姿勢）、二段跳、喝治癒藥水 / 精力藥水。

### 4. 至少三種敵人，攻擊外觀不同且有粒子特效
| 敵人 | 關卡 | 攻擊方式 | 攻擊特效 |
|---|---|---|---|
| 蜘蛛 | 第一關 | 近戰撕咬；遠程吐蜘蛛絲（命中會被纏住）；被打後鑽進沙裡潛伏，再從玩家腳下跳出來咬人 | 揮擊火花；纏住時身上的粒子特效；鑽地時噴沙塵、潛伏時沙丘冒沙；跳出前地面出現紅色警示圈 |
| 沙蟲 | 第一關（西側低谷） | 地面分成四個象限，先依隨機順序亮起提示；接著每一波只有對應順序的那格安全，其他格隨機有沙蟲從地底竄出咬人，要記住順序撐過四輪（前三輪各 4 波，最後一輪 6 波） | 象限亮光提示、冒出前地面噴沙與震動、竄出時的沙塵爆發與鏡頭震動 |
| 時鐘 Boss「時間吞噬者」 | 第一關 | 衝刺撞擊（衝刺前轉向玩家、臉上的時鐘脹縮預告）；召喚站立的時鐘陷阱；在玩家腳下放平躺的時鐘倒數，中招會被定身 | 落地震波光環；時鐘陷阱的黃色閃光與觸發光環；被定身時玩家變灰 |
| 聖騎士 | 第二關 | 近戰三段連擊 | 橘色揮砍火花、命中火花 |
| 敵艦弓箭手 | 第二關 | 從船上遠程射箭 | 箭矢拖尾、開弓煙霧、命中粒子 |
| 骷髏（一般 / 伏擊） | 第三關 | 近戰連擊；伏擊型從天而降或從地底鑽出 | 揮砍火花；落點紅圈與衝擊特效 |
| 石巨人 Boss | 第三關 | 揮擊、重砸、咆哮、光束、跳砸、召喚小怪 | 地面預警圈、衝擊波、光束、狂暴時的發光特效 |

### 5. 會動態改變的 GUI
- 左上角血量條（受傷時畫面閃紅）、剩餘生命數；血條下方的精力條（精力不夠時閃紅）。
- Boss 血條（含延遲扣血的效果）與 Boss 台詞。
- 右上角動態小地圖、已獲得能力清單。
- 右下角道具欄（治癒藥水剩餘 / 總數、精力藥水數量）、喝藥水進度條。
- 第二關的氧氣條；第一關被定身時的倒數秒數、地面時鐘陷阱的倒數秒數。

### 6. 散佈在每個關卡的補血道具
- 第一關：3 座營火散佈在地圖上（包含 Boss 廣場旁），走近按 E 點燃回復 40% 最大生命；每座只能用一次，死亡後不會恢復。另外可以用草藥向商人購買治癒藥水（回復 30%）。
- 第二關：6 個紅十字補血道具（`HealthPickup`，漂浮旋轉，走過去自動撿起回 30 HP；滿血時不會被撿走）。
- 第三關：紅十字補血道具在地下城生成時自動散佈在房間裡。

### 7. 背景音樂與完整音效
- 主選單、三個關卡各有不同的背景音樂；Boss 戰開始時切換成 Boss 戰音樂。
- 玩家受傷、敵人受傷（小怪、蜘蛛、時鐘 Boss、石巨人）都有受擊音效。
- 其他音效：揮劍、命中、盾擊、射箭、腳步、跳躍落地、撿道具、喝藥水、深淵印記爆發、時鐘滴答倒數、對話翻頁、購買、傳送門、檢查點啟用等。

### 8. 玩家狀態切換關卡時保持不變
- 換關卡時保留：目前血量、最大生命、跑速 / 攻擊力升級、能力路線與已獲得能力、背包（草藥、治癒藥水、精力藥水）、剩餘生命數。
- 存檔 / 讀檔時也會一起保存與還原。

### 9. Cinemachine 運鏡
- Main Camera 上有 CinemachineBrain，CinemachineCamera 使用 Third Person Follow 跟隨玩家（不是固定鏡頭），可以用滑鼠轉動視角、滾輪調整遠近。
- 開啟 Third Person Follow 的 Avoid Obstacles，鏡頭被牆擋住時會自動往前拉，不會穿牆；另外處理了注視點頂進天花板時的穿牆問題。

**7. 其他（請助教參考）**
- 能力路線系統：第一株能力植物三選一決定路線（跑速 / 力量 / 血量），Boss 房的第二株植物從該路線的 6 種進階能力中隨機出現 3 種讓玩家選（例如二段跳、翻滾後加速、蓄力重擊、連擊增傷、深淵印記傷害重現、定時護盾、低血減傷、惡魔型態定時無敵等）。
- 第一關劇情對話：開場、沙蟲低谷、Boss 開戰與倒下都有劇情對話，對話框左右兩側即時拍攝玩家與對方的 3D 半身像，說話的一方會亮起；開場後商人頭上出現指引標記，帶玩家去找他。
- 商人引導式對話與購買：對話框逐字顯示，對話中直接用草藥購買道具。
- 檢查點與 Boss 戰重置：Boss 戰中死亡會在石碑旁復活、Boss 回滿血；已經打倒的敵人、用過的營火不會因為死亡而恢復。
- 玩家技能：翻滾閃避（無敵時間）、能量牽引、盾牌格擋 / 盾擊。

## 基礎操作方式

| 按鍵 | 功能 |
|---|---|
| W A S D | 移動 |
| 左 Shift | 衝刺 |
| 空白鍵 | 跳躍（對話中：下一句） |
| V | 翻滾閃避 |
| 滑鼠 / 滾輪 | 轉動鏡頭 / 鏡頭遠近 |
| 滑鼠左鍵 | 近戰連擊（有「巧匠天工」能力時長按蓄力重擊） |
| 滑鼠右鍵 | 按一下舉盾衝撞、按住格擋；在船上按住瞄準 |
| 滑鼠中鍵 | 能量牽引 |
| E | 互動（採草藥、營火、能力植物、商人對話、傳送門、上船） |
| Q / G | 喝治癒藥水 / 喝精力藥水 |
| 1 / 2 / 3 | 能力選擇、商店購買 |

| Esc | 暫停選單（存檔 / 讀檔 / 重新開始本關） |
