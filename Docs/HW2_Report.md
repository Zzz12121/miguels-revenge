## 2. 基礎操作方式

| 按鍵 | 動作 |
|---|---|
| W A S D | 移動（相對鏡頭方向） |
| 左 Shift | 衝刺 |
| 空白鍵 | 跳躍 |
| 滑鼠移動 | 轉動鏡頭 |
| 滑鼠滾輪 | 鏡頭遠近 |
| 滑鼠左鍵 | 近戰三段連擊 |
| 滑鼠右鍵（按一下） | 舉盾衝撞：把前方敵人撞開 |
| 滑鼠右鍵（按住） | 舉盾格擋：正面攻擊完全擋下，連續擋到第 3 下會破防扣血（畫面下方顯示還能擋幾下） |
| 滑鼠右鍵（按住，在船上） | 在船上用弓箭時瞄準（鏡頭拉近放大），左鍵射箭 |
| E | 互動（傳送門、撿能力植物、採集、上船、開門） |
| M | 顯示 / 隱藏小地圖 |
| Esc | 暫停選單（繼續 / 存檔 / 讀檔 / 重新開始本關 / 回主選單） |
| 駕船時 W / S、A / D | 前進後退、轉向 |

### 版本控制與同步開發

- 使用 **Git + GitHub**，主 repo：`Zzz12121/miguels-revenge`，加入 Unity 官方的 `.gitignore`（不上傳 Library、Temp、Logs、Builds…）。
- `.gitattributes` 統一場景 / Prefab 的換行符號；`.asset` 用 `text=auto`，避免二進位的地形、光照資料被換行轉換弄壞。
- 每個人在自己的分支開發（例如 `planet`、`isc`、`Kevin`），或 fork 之後在 fork 開分支；完成後開 **Pull Request** 合併進 `main`。
- 開工前先 `git fetch` + 合併最新的 `main`，減少衝突；同一個場景盡量只由一個人同時修改，遇到場景衝突時由負責該關的組員處理。
- 搬移檔案時連同 `.meta` 一起搬，Prefab / 場景之間的引用才不會斷。
