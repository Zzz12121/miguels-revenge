# 主道場屋頂：四張獨立多視圖參考

使用內建 imagegen，以原始屋頂參考生成並目視檢查。對應目前 Tripo Multi-view 的欄位：

| Tripo 欄位 | 上傳圖片 |
| --- | --- |
| Front | 01_Front.png |
| Left | 02_Left.png |
| Right | 03_Right.png |
| Back | 04_Back.png |

Front 與 Back 是長邊屋坡；Left 與 Right 是短邊端坡，屋脊朝畫面深處延伸。屋頂採前後、左右對稱設計，因此相對視角相似是預期結果。

四張皆為單獨 PNG，可逐一上傳，不要合成拼圖。Root 旁的 RoofMultiView-v1.zip 包含四張 PNG。

這些是 AI 生成的多視角設計參考，不是從已驗證的同一份 3D 網格輸出的正投影；構件尺度、瓦片與支撐細節可能仍有差異，不能當作精密施工圖。已修掉第一輪側面被畫成縮窄正面的錯誤，但無法由影像保證重建的背面、底部或接縫。生成模型後仍需轉看四面與底部，檢查輪廓、屋脊、簷角和可用的屋內空間。

完整提示保存在本資料夾的 IMAGEGEN_PROMPTS.txt。第一次錯誤的側面候選未納入此包。
