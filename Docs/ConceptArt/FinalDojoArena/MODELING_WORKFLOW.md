# 從設計圖到可用建築：建模與組裝路線

日期：2026-11-08。以下保留最初建模路線。最新進度：已清理並貼圖屋頂，建立主道場、附館與完整庭院的實際 Unity 場景，詳見 [建築實作與交接](BUILDING_IMPLEMENTATION.md)。

## 建造方式

完整建築由「精確可通行的結構」與「造型零件」組成。地板、隔牆、門洞、柱位與樓梯先按室內需求在 Unity 或 Blender 搭建；屋頂、鳥居、石燈籠、盆栽和家具可交給 Tripo 製作，再匯入 Unity 組裝。這樣可以依房間安排調整尺寸及碰撞，也能保留可拆卸屋頂與可開門的獨立物件。

概念剖視圖是房間規劃參考，不保證整棟生成後就有相同的空腔、相通門洞或精確比例。已生成的外觀模型仍要檢查內部與背面。

| 部分 | 建議來源 | 第一輪檢查 |
| --- | --- | --- |
| 基座、室內外地板與階梯 | Unity／Blender 按尺寸搭建 | 高度、平整度、樓梯與門檻通行 |
| 木柱、樑、外牆、隔牆、門框 | 重複利用的規則結構模組 | 房間尺寸、門洞與動線、拼接縫 |
| 障子門／窗 | 獨立門框與門片 | 門片厚度、滑動軸、材質；互動另整合 |
| 主道場灰瓦屋頂 | Tripo 第一個造型模型 | 輪廓、背面、簷角、底部、面數 |
| 側翼與迴廊屋頂 | 後續獨立模組 | 與樑柱的接縫、轉角與重複拼接 |
| 鳥居、石燈籠、庭石與盆栽 | Tripo 獨立物件 | 正常人物尺度、底部、模型重用 |
| 茶桌、坐墊、武器架與收納箱 | Tripo 或簡單規則模型 | 放置位置與通行空間 |

## 現在先試第一個模型：主道場屋頂

輸入圖：TripoInputs/01-main-dojo-roof-reference-v1.png。

這是獨立的完整屋頂三分之四參考，使用內建 imagegen 依照已提供的整體設計圖生成。圖裡只有屋頂與簷下支撐，不包含房屋牆壁、基座或庭院。隱藏的背面及底面仍須在生成後檢查。

1. 打開 Tripo 的 Model，選 Smart Mesh 路線；若介面顯示模型版本，可選 P2.0。
2. 使用單張 Image-to-3D，上傳上述屋頂參考圖。
3. 第一輪建議用 Triangle、約 20,000 triangles 作為比較起點。這是這個零件的試生設定，並非整個場景的效能保證。先看簷角與整體輪廓是否保留下來，再依結果調整。
4. 生成後轉看正面、背面、側面與下方，檢查屋簷是否崩塌、背坡是否完整、底部是否產生不需要的大實心塊。需要時補同一屋頂設計的一致視角或在 Blender 修整。
5. 確認模型後再檢查貼圖、匯出 FBX 和材質貼圖。屋頂屬於靜態建物零件，不需要角色骨架。
6. 匯入 Unity 後，以門高、柱距和白盒房間為尺度依據定位屋頂，調整模型或模組接縫。保留可回復的原始模型，避免為了對齊而任意拉扁瓦片。

選單名稱與可見版本依使用者當下介面為準。官方工作流參考：https://www.tripo3d.ai/tutorials/workflow-game-scene 。

## 後續順序

主道場白盒／結構 → 主屋頂試生與比例校對 → 側翼、迴廊與圍牆模組 → 門窗 → 鳥居與庭園裝飾 → 室內道具 → 材質、光照與效能檢查。先保證主結構和通行空間，再補裝飾。

本步只準備參考圖與路線，未安裝套件、未提交 Git，也未改寫移動、Boss AI 或動態戰場系統。
