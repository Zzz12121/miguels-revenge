# 道場門縫、墨影、水墨球與貼地形霧

2026-11-15。此版本覆蓋 `DOJO_SCENIC_REVISION.md` 的墨影速度、瞬移接招、水墨外觀與外側霧設定。

最後追加：玩家在老頭鏡頭期間暗中移位的位置改為石頭路85%（大門Z5至露臺Z76.6，落點Z65.86）。賞景鏡頭在前2.2秒由背後繞到前方160°，距離約4.2m，保留上半身與周圍，不貼臉。老頭被牆完全遮住且前方0.9m仍看不到時才以6倍速度走過隱藏段；可見段維持原速。分鏡隨路段完成就切換，不停在牆角空等。

- **門板**：兩扇尺寸改為 5.75×6.12m；保留原鉸鏈、開門互動與推門動畫，門板外緣稍微伸入門柱，中央正好相接，上端銜接橫樑。`DojoGateFit.Fit` 可重建，檢查中央縫為0，兩外緣±5.75m。
- **墨影速度**：道場前後追擊分身從基礎 `cloneMoveSpeed` 的2倍降為1.4倍，即目前速度×0.7。生產形態保存的基礎值4m/s，所以實際8→5.6m/s。靶場未啟用追前後方的分身維持原速度。
- **瞬移接招**：`DojoCalligraphyEncounter.SelectTeleportFollowup` 各50%選擇技能2（墨影近戰）或技能1（連筆四式）。原近戰距離判斷及其他循環仍保留；抽到近戰但玩家已跑遠時照舊安全改遠攻。2000次固定種子選樣：991近戰、1009連筆；也實際驗證兩招可施放。
- **墨影等待**：墨影近戰完成後，直到這次的戰鬥分身全數消散並銷毀才繼續。死亡旗標或開始淡出不算已消失。
- **原素材絲狀水墨**：使用者否決自製球體後，已移除該球體、球面材質與自製尾巴 shader。整團只用 Ying Yang 的 `ARPG_White__Casting_Hand_attach`、`ARPG_White__Embers`，偶爾用 `ARPG_White__Hit_Nova_Heavy` / `ARPG_White__Projectile_Muzzle_Flash`。保留原網格、貼圖、扭曲及UV流動；只在執行時複製材質並反轉原色／粒子色。黑色實例切換原 shader 已支援的 alpha 混色，並用原流動主貼圖的紅色通道作透明度，避免加法黑色消失及方形底板。
- **大小與繞行**：十組主要原特效各自有不同大小、半徑0.15–0.7m、軌道傾角及正反48–105°/s角速度；整體前進時每組仍獨立繞中心。成對隨機反色，使每組都有一半反色機率，並同時保有黑、白兩色。
- **尾巴與清理**：沿飛過的位置每0.08秒放少量較小的原素材 Embers / Casting；尾巴特效脫離中心移動、留在世界座標。所有粒子壽命固定0.5s，臨時特效及複製材質一起清理。主要軌道發射器維持到鏡頭回玩家；不加自製球或自製粒子外觀。
- **毛筆重組**：保持毛筆原始尺寸，使用 `DojoBrushManifestation` 的握柄往外顯現遮罩，2.1秒內由流向手掌的水墨逐段重建筆桿、筆尖，再恢復原材質。不使用整支實體毛筆縮放出現。
- **靶場膠囊**：刪除 `VoidRend_DummyTarget`、`VoidRend_Target_Left`、`VoidRend_Target_Moving` 三個可見膠囊靶；重建器改用無模型的瞄準定位點，不重新建立膠囊模型。玩家及角色本身的必要碰撞體保留。
- **離場交接**：過第一鳥居後鏡頭照舊回玩家，但水墨沿通行路線繼續往 (74,3.6,132) 飛；攝影機交接後下一幀才停用水墨，並接玩家對話。實測鏡頭回切前0.7秒水墨還在移動，前進約7.83m，交接前保持啟用。
- **外側地形霧**：移除方盒霧牆的網格，改用實際 Terrain 高度和表面法線建立三層薄霧殼，離地形約0.35–1.15m，外層漸淡、邊界淡出，程序紋理緩慢流動。使用一般深度測試，不會在天空畫出巨大矩形。庭院內及後山內觀察者完全略過這層外側霧；原山道 FogZone、ValleyMist、河流及全場 RenderSettings 不變。
