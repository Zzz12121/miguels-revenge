# 墨海向空氣滲墨（2026-10-25）

依最新美術方向，海面不再以黏稠捲浪表現。移除原本的捲浪網格，改成近乎平面的深色墨池，加上遍布墨海、緩慢向上滲出再消散的分岔墨霧。

- 每個滲墨位置都有自己的高度、週期與時間偏移，生成後先連著墨面上升，接著向外分岔、稀釋，最後底部斷開並淡去。
- 每處包含主幹、兩路分支與四路細分支；材質以多尺度噪聲與流動侵蝕打散輪廓，保留墨芯和薄霧邊緣。
- 等面積螺旋加上擾動，把位置散佈到中心與外圍。各處生命週期錯開，接替時不會全體同時消失。
- 海面只保留微小起伏，關閉原本的高浪與亮色浪脊。空中墨霧不寫深度、不發光、不投影，沿用地形深度遮擋。
- 平面本身也持續流動：局部渦心大小、形狀、方向與轉速不同，螺旋會捲動不規則墨斑和細墨紋。外緣帶有持續變動的渲染輪廓與淡墨濕邊，海面仍保持平薄。
- 這是純視覺變更，沒有加入碰撞或新的推力；既有落海傷害、緩速與首次插筆擊飛沿用原流程。

## 調整位置

靶場選 `CalligraphyElder` → `Calligraphy Boss Combat` → `9 墨相鎮海／浮墨天階（全部參數）` → `Ink Avatar Ultimate` → `Sea`。

| 欄位 | 預設 | 用途 |
|---|---|---|
| Air Plume Count | 112 | 整片墨海的滲墨位置數，上限 160 |
| Air Height | 2.5–7 | 墨絲滲入空氣的高度範圍，公尺 |
| Air Lifetime | 3.2–5.5 | 每一團墨從生成到消散的秒數範圍 |
| Air Spread | 2.3 | 向側面分岔、擴散的幅度 |
| Air Opacity | .62 | 空中墨霧濃度，會乘上海面消散透明度 |
| Air Branching | .8 | 細碎墨絲和侵蝕邊緣的強度 |
| Wave Amplitude | .18 | 表面輕微起伏；程式會限制在 .35 以下 |
| Churn Speed | .85 | 墨面平面流動與螺旋轉動速度 |
| Vortex Density | 1 | 局部螺旋的密度，越高渦旋越小且越密 |
| Vortex Strength | 1.3 | 螺旋捲動幅度與墨紋對比 |
| Edge Strength | .8 | 細墨紋與渲染邊緣的顯現強度 |
| Diffusion Material | M_InkAvatarDiffusion | 可共用的空氣滲墨材質 |

數量、高度與週期在每次施放建立時取樣；改完重新施放即可。擴散幅度、透明度、分形程度與表面起伏可於播放中預覽。Play Mode 的值不會永久儲存。
