# 河鎮 V3：實作與交付紀錄

規格來源：`Inkbound_Town_V3` 的六份 Markdown 與 52 張引用圖片。V3 全城連續交戰規則優先；舊布局圖的固定決戰廣場不採用。店面與場景標題維持使用者要求，不放「墨中故城／布／布莊／酒」等文字。

## 場景與操作

- 場景：`Assets/_Project/Scenes/InkboundTown_Exploration.unity`。沿用路徑以保留既有引用，現在已包含第二階段戰鬥。
- 道場：既有半血逃離演出結束後，最後飛行路點出現展開的畫卷；玩家靠近並按 **E** 才進城。Boss 血量上限、剩餘血量與玩家狀態接續。
- 直接開河鎮：Boss 預設半血，靠近老者或先攻擊即可開戰。主街、橋、河岸、巷弄、茶館與庭院連通；沒有廣場觸發、區域封鎖、競技場牽引或跨區補血。
- 玩家死亡沿用原有重生流程；Boss 回到本次入城血量與起點。擊敗老者後市井與船仍繼續運作。
- 重建：結束 Play 並儲存場景後，選 **GeminiGrowUp → Inkbound Town V3 → Rebuild town**。真正來源是 `InkboundTownBuilder` 的 partial 檔案，並非只手改生成結果。

## 美術與資產

八種建築原型、各兩個變體：布商、茶樓、酒肆、藥鋪、蒸食、魚販、陶作、住宅。入口、樓層、廊檐、門窗與用途道具不同。主街先做約 28m 切片，再擴展屋群、雙橋、碼頭與棋院。近景瓦頂和窗格重用專案既有 Soswaewon 模型；瓦頂原模型的屋脊沿 Z，組裝時轉向，避免山牆穿出屋面。梁柱、器皿、布捲、蒸籠、棋具、船形與植栽另做可重建曲面幾何。

植栽包含柳、層松、節竹、梅、闊葉樹、芭蕉、蘆葦、荷；柳與闊葉各有額外變體。枝條收尖、非對稱分枝，近遠 LOD 分別保存幹枝與減量葉片。闊葉的既有模型實際為 Maple；「OldCamphor」是模組用途名稱，不宣稱植物學上是樟樹。

道具功能組涵蓋布架／布捲／摺布、茶桌／凳／壺／杯／托盤／茶櫃、酒罈／蓋布、藥櫃／藥缽／杵／藥罐、蒸籠／竹箅／碗／食物、魚盆／魚／籃／網／繫樁／繩、陶作器皿，以及棋盤／棋子／旁置茶具；另有竹簾、屏風、無字掛畫、花盆、燈籠等。用途不依賴文字招牌。

100 個居民生活流程，另有兩船的划船人物。居民使用八種既有外觀，走動、交談、飲茶、整理貨物、磨藥、修網與下棋各自有時間相位。歷史居民及指定貨物沒有實體阻擋或傷害／鎖定元件；地面、牆、屋檐、柱、橋仍保留碰撞。

材質按牆、木、瓦、石、布、陶、樹皮、葉片、人物分族。宣紙底色、方向筆痕、低頻暈染、中頻墨紋與局部破邊在材質內完成，沒有用全局去色濾鏡替代。原場景 Linear 色彩空間中避免重複 `.linear` 轉換；圓管法線與陰影 Cull 修正後，不再以黑色陰影雜訊遮掩細節。水面是低頻破碎倒影與水平筆痕，D3D 投影 UV 翻轉已修正。

## 工程界線

- `InkboundTownEncounter` 只負責河鎮的尋路、既有招式選擇、入城血量與重試。沿用共享玩家控制、相機、傷害與老者技能。
- Boss 使用獨立 `PF_InkboundTown_Elder.prefab`，避免改寫使用者原先已修改的共享老者 Prefab。
- NavMesh 使用專案既有 AI Navigation；依物理碰撞烘焙，排除玩家、Boss 與可穿透生活物件。
- 河鎮行走接合層修正轉角前過早停止；共享行走的地面射線可能先命中橋下岸面，因此保留原牆面掃掠，以導航路面校正行走腳高，避免老者走到橋下。沒有改寫共享玩家或 Boss 的移動實作。
- 依左右空間、頭頂、地面與可落點選既有技能；過遠先追近，休息時間從招式結束後計算。大型原畫中世界／浮墨天階不強塞進狹巷。
- 四個共享 VFX 檔案只加可選的視覺掃掠通知，沒有改傷害判定；場景沒有訂閱者時不建立河鎮散墨。
- `InkboundEcho` 保存四個局部接觸區，以當前烘焙動畫頂點為回流目標；濃墨、薄墨、彎曲墨絲、分岔與細滴在同一動態網格中。停用的來源會釋放接觸，未受擾動部位直接跟隨動畫。透明度為零的面片收成退化三角形，避免仍耗填色。
- 同時最多五個高品質散墨，超額改用 32 個樣本；技能掃掠來源以 32 格池重用。不是整個人物透明度淡出再淡入。
- 沒有新增或移除套件。原有未提交修改另行保留，未納入本次提交。

## 保留的差異與使用者驗收範圍

美術已有實際模型、材質與布局改善，但概念圖的手繪不規則度、濕墨邊緣融合與更自然的密集屋群，仍高於目前即時 3D 呈現；不能說兩者完全相同。部分後排街道仍較整齊，室內角色姿勢沿用既有骨架而非每位另做手工動畫。玩家與既有 Boss 技能保留原有彩色辨識，環境採淡墨，因此沒有把人物與預警整體去色。

本輪已做必要整合檢查，沒有新增一般測試框架、全面重寫隊友系統或大量泛用測試。完整長時間遊玩、所有技能組合、每個牆角翻滾與不同機器效能仍由使用者實玩驗收。已知未取得的編輯前效能保持明示，不為填滿清單捏造數據。
