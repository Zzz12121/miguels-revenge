# 靠河的寬市集街

保留現有小鎮內容，只調整老者所在的第一段市集街。八間市集房屋向河邊移動，靠河那排的背面與原河岸房屋背面靠近；兩排正門分別朝向市集與河岸。原河岸房屋的位置、朝向保持，沒有刪除／重建房屋或改寫戰鬥流程。

- 市集西排 X：`-51.1 → -49.1`；東排 X：`-36.9 → -29.65`。
- 街道中線 X：`-44 → -39.375`，往河邊移 4.625 公尺。
- 石板鋪面寬度：`6 → 13.2` 公尺；屋簷／廊下之間最窄淨空：`3.1 → 8.35` 公尺。
- 市集與河岸背側屋簷間距約 0.2–1 公尺，收掉原先的大空巷，又避免屋簷相穿。
- 老者初始位置：`(-39.375, 0, 16)`。十二名市集行人的路線、店主／茶客、門牌坊、門檻、盆栽與附近樹木隨布局移動；居民仍為既有比例與生活動作。
- 牌坊橫向加寬，街面碰撞同步拓寬；合併石板網格只改原市集那 24 個頂點，交叉巷道、河岸與橋接點保持。重新烘焙原城鎮導航資產，市集仍可繞經路口通往河岸。

既有環山、居民／家具多點黑墨、使用者散墨參數及 ForestIsland 傳送／河鎮片尾修改均保留。

來源為 `Assets/_Project/Scripts/Editor/InkboundTownBuilder.MarketLayout.cs`。現有場景使用選單 **GeminiGrowUp → Inkbound Town V3 → Widen and join riverside market**；場景內 `06 Widened market beside the riverside block` 空節點防止重複套用。完整生成器也會套用相同布局。這次使用局部更新，沒有完整重建小鎮。

`output/inkbound-town/riverside-market/` 的 01／03 為相同視角的前後俯瞰，02／04 比較街寬，05 顯示背靠背街廓。`layout-checks.json` 確認居民與 Renderer 數量、河岸房屋、環山與散墨設定保留，屋簷沒有相穿，導航通往河岸。必要 W 行走檢查前進約 3.35 公尺且保持接地；該次已啟動的戰鬥造成受傷，不把血量不變列為通過項目。主要實玩仍交給使用者。
